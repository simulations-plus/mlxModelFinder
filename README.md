# mlxModelFinder

Automated structural model selection for [Monolix](https://monolix.lixoft.com/).

`mlxModelFinder` is an R package that explores a user-defined search space of pharmacokinetic models and identifies the best structure using one of several optimization strategies:

- **Exhaustive search** — evaluate every candidate
- **Ant Colony Optimization (ACO)** — probabilistic, iterative exploration
- **Decision tree** — stepwise forward selection
